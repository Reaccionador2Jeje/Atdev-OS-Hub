# AtDev Billing — Hybrid plans (AtDev OS Hub)

**Status:** proposal only. Access to open-source operating-system information, downloads, and community resources remains free.

## Hybrid model

Do not charge for essential OS information, security notices, or access to open-source downloads. Optional monetization may include voluntary support, curated convenience tools, or hosted services only after implementation. Never make security updates or vulnerability information a paid-only feature.

## Proposed tiers (CLP/month; exploratory)

| Plan | Reference price | Scope |
| --- | ---: | --- |
| Community | $0 | Essential hub content and downloads |
| Supporter | Voluntary | Optional contribution and acknowledgment |
| Plus | $490 | Future convenience/customization features, if implemented |

No checkout is active. Any future paid offering must preserve open access to essential security information and clearly distinguish official downloads from third-party content. Adult account-owner review is required before real-money launch.
